# 基础页面

原始 E 盘工程未修改：目录授权通过后，实际写入仍被运行环境拒绝。新增功能位于新版副本和 GitHub 更新中。

## 使用

用 Unity 2022.3.42f1c1 打开项目，在 SampleScene 点击 Play，标题页面会自动出现。点击“开始探险”进入当前场景，按 Esc 暂停。无需新增场景、预制体或 Inspector 绑定。

- 标题：开始 / 继续、设置、操作说明、退出。
- 暂停：继续、设置、操作说明、返回标题、退出。
- 设置：主音量、全屏、窗口分辨率。音量拖动即时预听；返回时撤销未保存的音量，应用后使用 PlayerPrefs 持久化。当前项目本身尚无背景音乐或音效资产。
- 显示变更：构建版给出 15 秒确认，取消 / 超时恢复原显示模式和尺寸。全屏采用桌面全屏，分辨率控制窗口模式的大小。编辑器内保存设置但不改 Game View。
- 返回标题：保留当前内存中的探险；退出游戏仍没有跨会话存档，因此弹窗会提示。
- Esc 优先级：下拉列表 → 当前设置 / 帮助 / 确认页 → 暂停 / 继续；游戏内背包、冶炼、建造模式先关闭，再次 Esc 才暂停。

## 画风与适配

使用原有像素精灵搭配深海蓝底、木棕方框、奶油文字、苔绿主按钮和金色选择状态。背景以 Point 采样的低分辨率贴图和像素方块组成；装饰小岛使用非缩放时间轻微浮动，暂停时仍可操作 UI。

UGUI CanvasScaler 以 1280×720 为参考，适合横向桌面窗口。中文优先使用已安装的雅黑等字体；没有可用中文字体时，界面自动采用英文和 Unity 内置字体。没有复制系统字体或引入素材许可证。

## 实现

GameMenuController.cs 通过 RuntimeInitializeOnLoadMethod 在 SampleScene 加载后创建一个独立控制器及 MenuCanvas。MenuCanvas 隐藏后控制器仍保持激活，Esc 可重新打开暂停。各页面复用既有节点，不在开关时反复创建纹理或按钮监听。生成的背景纹理、精灵和动态字体在销毁时释放。

菜单打开时 Time.timeScale=0，玩家与敌人停止输入并清零速度；背包 / 冶炼 / 建造预览主动关闭，旧 Canvas 的交互状态保存并恢复。关闭菜单当帧仍拦截游戏输入，防止开始 / 继续按钮点击穿透。Esc 由旧子 UI 在 Update 消费，菜单在 LateUpdate 决定是否暂停。

本次修改的旧脚本为 PlayerController、EnemyAI、Building、BuildingPlacer、TileClickHandler、InventoryUI、CraftingUI。未修复分析报告中的无关采集 / 经济 / 缺失资源问题。

## 验证

已做独立代码审查、对照本机 Unity UGUI 1.0 API、输入调用与 Esc 顺序审查，并检查新脚本及 .meta、项目副本文件和打包完整性。本运行环境无法启动 Unity，因此没有完成 Unity 导入、编译或实际试玩验证。

在编辑器或构建版检查：

1. 首次进入为标题页；1–4、B、E、空格和点击背景不应影响世界，敌人不攻击。
2. 开始后可移动采集；Esc 暂停，继续按钮或 Esc 恢复；来回切换多次 Canvas / EventSystem 数量保持稳定。
3. 背包、冶炼、建造模式打开时首次 Esc 只关闭旧界面；下一次才暂停。
4. 分辨率下拉展开时 Esc 只收起下拉；再次才离开设置。
5. 音量取消恢复、应用保存；重启后设置恢复。当前 Demo 没有音频，实际声音应在添加音源后验证。
6. 构建版切换全屏 / 窗口尺寸；确认保存，取消或等待 15 秒回滚，回滚后的控件与显示保持一致。
7. 从游戏返回标题，打开设置 / 帮助 / 显示确认并返回；点击继续应保留本次背包与地图。
8. 退出取消可恢复；确认在编辑器停止 Play、在桌面构建退出应用。
9. 检查 800×600、960×600、1280×720、1920×1080 的文字、按钮、下拉滚动和键盘导航。
